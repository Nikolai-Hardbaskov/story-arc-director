# Story Arc Director v0.3.0 — Сюжетный режиссёр для SillyTavern

SillyTavern UI-расширение для генерации ролевой истории с пятью актами и логическим финалом. Режиссёр направляет происходящее **без принуждения игрока к заранее выбранным репликам и поступкам**. В «умном» режиме после ответов модели проверяет фактически сыгранные события и, когда нужно, меняет будущие акты.

## Новое в версии 0.3.0

- **Комбинация жанров:** выбирайте до **4** жанров (например, «Романтика + Повседневность», «Ужасы + Мистика», «Спорт + Драма», «Фэнтези + Супергерои») из 5 компактных групп. Всего 34 жанра, включая тёмную романтику и эротику (18+).
- **Автоподбор:** без выбора модель определяет органичные жанровые направления на основе карточки персонажа, истории и вашей идеи.
- **Кнопка «Предложить жанры»:** отдельный запрос к текущей модели предлагает 1–3 жанра и объясняет почему; выбор можно сразу отредактировать перед созданием плана. Для автоподбора без кнопки дополнительных запросов **нет**.
- **Профессия ≠ жанр:** спортсмен может участвовать в романтике или мистике, врач — в приключениях; спортивная драма не навязывается из профессии.
- **Отношения и характер:** генератор, анализатор, скрытые подсказки и перепланирование получили явные инструкции сверяться с характером и заданным в карточке статусом отношений `{{char}}` и `{{user}}`. Если герои уже в паре, история не должна сбрасывать отношения к первому знакомству.
- **Память отношений:** интеллектуальный анализ может записывать наблюдаемый статус, текущую динамику, конкретные изменения и нерешённые разногласия. Эти записи доступны в «Памяти режиссёра». **Это интерпретация LLM, не безошибочное правило.**
- **Нет выбора атмосферы:** настроение свободно меняется с событиями; настройки атмосферы отсутствуют.

### Пример

Персонаж по карточке — заботливый, застенчивый спортсмен и парень игрока. Пользователь выбирает «Романтика + Повседневность». Режиссёр может придумать историю о совместных планах, переменах в жизни, встрече с друзьями и решении общего вопроса. Спортивные соревнования могут упоминаться как естественная часть его жизни, но не обязаны быть главным конфликтом. Изменение доверия должно вытекать из уже сыгранных действий, а не из потребности сценария в драме.

## Установка

1. Распакуйте ZIP: внутри должна быть папка `story-arc-director` с файлом `manifest.json`.
2. Скопируйте её в `SillyTavern/data/<ваш-пользователь>/extensions/`. Если ранее была установлена v0.1 или v0.2, **замените файлы** в той же папке; не создавайте рядом второй экземпляр.
3. Перезапустите SillyTavern и обновите браузерную страницу. Если панель старая, очистите кэш страницы.
4. Откройте **Extensions / Расширения → Сюжетный режиссёр v0.3**.

Для разработчиков есть также общесистемная папка `SillyTavern/public/scripts/extensions/third-party/story-arc-director/`. Встроенный установщик по Git URL обычно ожидает репозиторий, **локальный ZIP устанавливается копированием папки**.

## Использование

1. Откройте персонажа и чат; подключите API/модель в SillyTavern.
2. При желании введите идею и выберите до четырёх жанров. Если не хотите выбирать — оставьте включённым «Автоподбор». Можно сначала нажать «Предложить жанры».
3. Выберите режим: **Умный** (рекомендуется), **По числу ответов** или **Вручную**. В умном режиме можно анализировать раз в 1, 2, 3 или 5 ответов; по умолчанию — каждый ответ.
4. Нажмите **«Создать сюжет для этого чата»**. Расширение вызовет текущую модель и сохранит пятиактный сюжет в метаданных чата.
5. Играйте. В умном режиме после выбранного числа ответов происходит отдельный запрос анализа. Сцены переключаются по событиям, а при крупных отклонениях перепланируются только ещё не сыгранные акты.
6. В панели доступны **«Память режиссёра»**, **«Весь сюжетный план»**, ручная навигация, пауза и финал.

**Важно:** смена жанров в панели влияет на **следующее создание сюжета**; существующий план остаётся таким, каким был сгенерирован, пока вы не пересоздадите его (с подтверждением). Актуальная переписка от этого не удаляется.

## Существующие истории и обратная совместимость

- Чаты, созданные в v0.1 или v0.2, читаются из прежнего ключа метаданных `story_arc_director` без сброса сюжета.
- Старый одиночный `genre` при отображении трактуется как выбор из одного жанра; новая история записывает массив `genres`. Настройка `auto` превращается в пустой список (= автоподбор).
- Прежние истории без `relationship` в памяти продолжают работать. Новые наблюдения добавляются при анализе.
- Никакой миграции и удаления чатов вручную не требуется.

## Стоимость, приватность и ограничения

- Создание сюжета — **1 запрос** к выбранной модели. Кнопка предложения жанров — **ещё 1 запрос** при каждом нажатии. Умный анализ — обычно **1 запрос после каждого N-го ответа**, при существенном отклонении может быть дополнительный запрос на перепланирование.
- В запросах используются поля карточки, недавние сообщения и краткие записи о сюжете. При облачном API они передаются выбранному провайдеру модели. Расширение **не использует отдельный сервер**.
- Соответствие характеру, история отношений и логика финала достигаются инструкциями для LLM и памятью, поэтому **не гарантируются алгоритмически**. Модель иногда ошибается. При необходимости вручную меняйте акт или пересоздавайте план.
- Записи о взаимоотношениях создаются только при успешном анализе; система не устанавливает «число любви» и не придумывает статус, если карточка его не задаёт.
- Эротика обозначена как 18+: инструкции исключают сексуальные сцены с несовершеннолетними и требуют согласия. Фактическое поведение зависит от подключённой модели и правил её провайдера.
- Проверялись модульная логика и браузерная панель **с имитацией контекста SillyTavern**; реальная установка с конкретным API-провайдером ещё не проверялась.

## Файлы

- `manifest.json` — загрузка расширения и глобальный interceptor.
- `index.js` — панель, события SillyTavern, запросы модели, обновление метаданных.
- `story-core.mjs` — чистая логика, жанры, промпты, память и перепланирование.
- `settings.html` и `style.css` — UI.
- `tests/` — модульные тесты Node и smoke-тест браузерной панели.

## Тесты

Нужен Node.js 20+:

```bash
node --test tests/*.test.mjs
```

Опционально: Python с Playwright и установленный Chromium:

```bash
python tests/browser-smoke.py
```

Официальные API, на которые опирается расширение: `SillyTavern.getContext()`, `chatMetadata`, `saveMetadata()`, `generateRaw()`, `renderExtensionTemplateAsync()`, `setExtensionPrompt()`, `CHARACTER_MESSAGE_RENDERED`, `CHAT_CHANGED` и `generate_interceptor`. См. [документацию](https://docs.sillytavern.app/for-contributors/writing-extensions/).
